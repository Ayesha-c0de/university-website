# University Website

A responsive multi-page university website built with HTML and CSS as a learning and portfolio project.

## Live Demo

[View Live Demo](https://ayesha-c0de.github.io/university-website/)

## Technologies Used

* HTML5
* CSS3

## Features

* Multi-page university website
* Home page with university introduction and hero section
* Academic programs and degree information
* Department information
* Admissions information
* Facilities section with images
* Contact page with contact information and social media links
* Responsive layout for desktop and mobile devices
* CSS hover effects and interactive navigation

## What I Learned

This project helped me practice:

* Semantic HTML structure
* Creating multi-page websites
* CSS Flexbox
* CSS Grid
* Responsive web design with media queries
* Navigation between multiple HTML pages
* Organizing images and project files
* Creating reusable CSS styles
* Designing layouts for different screen sizes
* Deploying a static website with GitHub Pages

## Project Structure

The website is organized into separate HTML pages with a shared CSS stylesheet and image directory.

* `index.html` — Home page
* `programs.html` — Academic programs and degree information
* `departments.html` — University departments
* `admissions.html` — Admissions information
* `facilities.html` — University facilities
* `contact.html` — Contact information
* `style.css` — Main stylesheet
* `images/` — Images used throughout the website

## Running the Project Locally

Clone the repository:

```text
git clone https://github.com/ayesha-c0de/university-website.git
```

Navigate into the project directory:

```text
cd university-website
```

Open `index.html` in a browser.

## Note

This project is a frontend university website created for learning and portfolio purposes. The university, institutional information, and contact details are used for demonstration purposes.
